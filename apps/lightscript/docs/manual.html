LIGHTSCRIPT v2.0

A scriptable, code-first lighting console. Control every fixture parameter with a powerful command language, output over sACN (E1.31), and visualise your rig in real time.

Introduction

LightScript is a desktop lighting console built on Electron. Unlike traditional consoles where every action goes through menus and encoders, LightScript puts a command language at the centre. You type commands, LightScript executes them — instantly, precisely, and repeatably.

Everything in LightScript is a first-class object: fixtures, cues, presets, faders, effects, timelines, and variables. All of these can be created, recalled, and deleted from the command line. The four panels (Grouping Grid, Cuelist, Presets, Faders) are live views of your show state, not the primary input method.

Output is via sACN (ANSI E1.31) — broadcast over your network to any sACN-compatible node, switch, or dimmer rack.

Installation

Requirements

Node.js v18+ — download from nodejs.org (LTS recommended). npm is included.

Running from source

# Unzip the LightScript package, then:
cd lightscript
npm install     # downloads Electron (~100 MB, one-time)
npm start       # launches the app

Building a distributable

npm run build-win      # → dist/LightScript Setup.exe  (Windows)
npm run build-mac      # → dist/LightScript.dmg        (macOS)
npm run build-linux    # → dist/LightScript.AppImage   (Linux)
ℹ

Built files appear in the dist/ folder. The built app is self-contained — Node.js is not required on the target machine.

Quick Start

  • 1
    Patch your fixtures Go to the Patching tab, click + Add Fixture, choose a profile (e.g. Generic Moving Head 16CH), set the DMX start address, and click Patch Fixture.
  • 2
    Start sACN output Click the START button in the top bar, or go to sACN → Start sACN Output. The dot turns green when transmitting.
  • 3
    Select fixtures and test Click fixtures in the Grouping Grid to select them, then type SET FIX sel dimmer 255 in the command line and press Enter.
  • 4
    Store a cue Type STORE CUE.1 Full Stage to record your first cue. Hit GO ▶ to fire it.
  • 5
    Save your show Press Ctrl+S (or Cmd+S on Mac). LightScript saves everything — fixtures, cues, presets, faders, links, variables, and timelines — to a .lss file.

The Interface

Top Bar

Contains the tab switcher (Live / Patching / Links / 3D Viz / Settings), the show name badge, the sACN status cluster with live indicator dot and START/STOP button, and the system clock.

Live Tab — Four Panels

The Live tab is split into four equal panels. Each serves a different purpose:

PanelPurpose
Grouping GridVisual grid of all patched fixtures. Click to select/deselect. Selected fixtures are highlighted amber. Brightness and colour shown live.
CuelistYour show's cue sequence. GO / BACK / STOP buttons, per-cue jump buttons, fade and delay times shown.
PresetsIntensity (INT), Colour (COL), and Position (POS) presets. Click a preset to recall it on selected fixtures. Filter by type using the panel buttons.
FadersEight named faders. Drag the track up/down to set a level. GO button toggles between 0 and 80. RELEASE ALL zeroes all faders.

Programmer Bar

The thin bar between the panels and the command line shows the current selection (SEL), last parameter touched (PARAM), last value (VAL), current cue (CUE), and next cue (NEXT).

Command Line

The command line at the bottom is where you talk to LightScript. Press Enter to execute. ↑/↓ cycles through history. Tab accepts autocomplete. Shift+Enter opens the multiline editor for EFFECT and TIMELINE programming.

Command History

The scrollable pane above the command line shows the output of every command — green for success, red for errors, blue for info. Capped at 200 lines.

Patching Fixtures PATCHING TAB

Before you can control a fixture, it must be patched. Patching tells LightScript the fixture's DMX start address and channel layout.

Adding a fixture

  • 1
    Open the Patching tab Click "Patching" in the top tab bar.
  • 2
    Click + Add Fixture The Add Fixture modal opens. The next available address is pre-filled automatically.
  • 3
    Choose a profile and mode Select from the built-in profiles: Generic PAR, Generic Moving Head (8CH / 16CH), Generic LED Wash (7CH), Generic RGB, Generic RGBA, Generic Strobe, and Generic Hazer. The channel list is shown inline so you know exactly what each channel does.
  • 4
    Click Patch Fixture The fixture appears in the patch table and in the Grouping Grid on the Live tab.

Removing fixtures

Click the ✕ in the patch table, or use the command line: DELETE FIX.5 removes fixture 5, DELETE FIX.1-8 removes a range.

The Command Line

The command line is the heart of LightScript. Every action — setting a value, recording a cue, deleting a preset — is a command. Commands are typed in plain text and executed by pressing Enter.

Syntax overview

ACTION TARGET [PARAMETER] VALUE [OPTIONS]

Fixture selection syntax

SyntaxMeaningExample
FIX 1Single fixtureSET FIX 1 dimmer 255
FIX 1-8RangeSET FIX 1-8 dimmer 128
FIX 1,3,5Comma listSET FIX 1,3,5 red 255
FIX 1.dimmerDot notation for paramSET FIX 1.red 255
FIX selCurrently selectedSET FIX sel dimmer 0

Autocomplete

As you type, LightScript suggests completions. Press Tab to accept the top suggestion. Suggestions appear for all commands, subcommands, and parameter names.

Command history

Press ↑ to scroll back through previously executed commands. Press ↓ to move forward. The full session history is kept in memory.

Multiline editor

For EFFECT and TIMELINE commands which require multiple lines, type EFFECT or TIMELINE name and press Enter — the multiline editor opens automatically. You can also press Shift+Enter at any time to open it. See the Multiline Editor section for details.

Variables ($VAR$) ADVANCED

Variables let you store a value once and reference it anywhere in a command. Variable names are wrapped in dollar signs.

Assigning a variable

$ varname = value

# Examples:
$ level = 200
$ myfix = 1-8

Using a variable

# Use $level$ in place of a value:
SET FIX 1 dimmer $level$

# Use $myfix$ in place of a fixture spec:
FADE FIX $myfix$ dimmer 0 2000

Variables are resolved before the command is parsed, so they work in any position. They persist until the show is closed or a new show is loaded.

Variables in Links

The Links tab uses variables to capture parts of incoming OSC addresses. For example, a link with source /show/cue/$n$ captures the n segment of the OSC address and makes it available as $n$ in the target command. See Links (OSC).

SET COMMAND

Snaps a fixture parameter to a value instantly with no fade time.

SET FIX <id> [param] <value>
Instantly set one or more fixture parameters.
SET FIX 1 dimmer 255 — fixture 1 full
SET FIX 1-8 dimmer 128 — fixtures 1–8 to 50%
SET FIX 1,3,5 red 255 — red channel on fixtures 1, 3, 5
SET FIX 1.red 255 — dot notation shorthand
SET FIX sel dimmer 0 — zero dimmer on selected fixtures
⚠

SET fires immediately — no fade. If you want a transition use FADE instead.

FADE COMMAND

Fades a fixture parameter to a value over a specified time in milliseconds. The fade runs in the background — you can issue new commands while it is running.

FADE FIX <id> [param] <value> [time_ms]
Fade to value over time. Default fade time is 2000ms if not specified.
FADE FIX 1 dimmer 0 3000 — fade out fixture 1 over 3 seconds
FADE FIX 1-8 dimmer 255 1500 — fade up all in 1.5 seconds
FADE FIX 2 blue 255 500 — fade blue channel in 500ms
FADE FIX sel pan 200 4000 — slow pan fade on selection

Multiple fades on the same fixture/parameter can run simultaneously. Starting a new fade on the same fixture+parameter cancels the previous one for that channel.

To stop all running fades, click the ■ STOP button in the Cuelist panel header.

STORE COMMAND

Records a cue, preset, or fader label. The stored object can be recalled later.

STORE CUE.<num> <name>
Store the current programmer state as a cue. Fade time comes from the default fade time in Settings.
STORE CUE.1 Blackout
STORE CUE.10 Opening Scene
STORE PRESET.<TYPE>.<num> <name>
Store a preset. TYPE is INT (intensity), COL (colour), or POS (position).
STORE PRESET.INT.5 Half Stage
STORE PRESET.COL.3 Sunrise
STORE PRESET.POS.2 Stage Left
STORE FADER.<num> <name>
Set the label for a fader strip (1–8).
STORE FADER.1 Grand Master
STORE FADER.3 Wash

DELETE COMMAND

Permanently removes a stored object. DEL is an accepted shorthand.

DELETE <target>
DELETE CUE.3 — delete cue number 3
DELETE PRESET.INT.2 — delete intensity preset 2
DELETE PRESET.COL.1 — delete colour preset 1
DELETE FIX.5 — unpatch fixture 5
DELETE FIX.1-4 — unpatch fixtures 1 through 4
DELETE LINK.1 — delete link #1 (1-indexed)
DELETE TIMELINE myshow — delete named timeline
⚠

DELETE is immediate and cannot be undone within the current session. Save your show before making large deletions.

EFFECT COMMAND

Creates a looping, multi-step effect. Each step is a command followed by a hold time in milliseconds. The effect loops indefinitely until explicitly stopped.

Syntax

Type EFFECT and press Enter. The multiline editor opens. Write one command per line, with the hold time (ms) as the last number on each line. Press STORE when done.

# Simple chase effect (500ms per step):
SET FIX 1-4  dimmer 255  500
SET FIX 1-4  dimmer 0    500
SET FIX 5-8  dimmer 255  500
SET FIX 5-8  dimmer 0    500

# Colour cycle (1000ms per step):
SET FIX 1-8  red 255  1000
SET FIX 1-8  green 255  1000
SET FIX 1-8  blue 255  1000

After storing, the effect is assigned an internal key (e.g. EFX1718200000) and can be recalled from the show file. Press RUN ▶ in the editor to preview steps live without storing.

TIMELINE COMMAND

A timeline is like an EFFECT but plays once (no loop) and has absolute time offsets instead of hold times. Timelines are show-wide and persist until deleted.

Syntax

Type TIMELINE myname and press Enter. The multiline editor opens in TIMELINE mode. Write one command per line with the time offset (ms from start) as the last number.

# 10-second show opener timeline:
SET FIX 1-24 dimmer 0      0       # start: blackout
FADE FIX 1-8  dimmer 255  3000   # 3s: fade up front wash
SET FIX 9-16  red 255     5000   # 5s: add red backs
FADE FIX 17-24 pan 200   7000   # 7s: pan spots
FADE FIX 1-24 dimmer 0   10000  # 10s: fade to black

Timelines are stored by name. Recall with TIMELINE myname. Delete with DELETE TIMELINE myname.

ℹ

The key difference between EFFECT and TIMELINE: EFFECT loops and uses relative hold times between steps; TIMELINE plays once and uses absolute time offsets from the start.

Multiline Editor EFFECT / TIMELINE

The multiline editor replaces the single-line bar when programming EFFECT and TIMELINE objects. It provides a code-editor experience with line numbers, syntax-aware placeholder text, and dedicated run/store controls.

Opening the editor

Three ways to open it:

  • Type EFFECT and press Enter
  • Type TIMELINE myname and press Enter
  • Press Shift+Enter at any time to open with current single-line content pre-filled

Editor controls

Line format

Each line is a standard LightScript command with a time argument appended as the last number on the line:

COMMAND ARGUMENTS  TIME_MS

# For EFFECT: TIME_MS is the hold time after this step (before next step fires)
SET FIX 1-8 dimmer 255  500    # hold for 500ms then go to next step

# For TIMELINE: TIME_MS is when this step fires relative to timeline start
SET FIX 1-8 dimmer 255  2000   # fires at t=2000ms from timeline start

Blank lines are ignored. The gutter on the left shows line numbers that update as you type.

sACN Output E1.31

LightScript transmits DMX data over the network using sACN (ANSI E1.31). No physical DMX interface is required — connect LightScript to any sACN-capable node, dimmer rack, or gateway on the same network.

How sACN works

LightScript sends UDP multicast packets to the standard sACN multicast addresses (239.255.0.<universe>) on port 5568. Each universe carries 512 DMX channels. Fixtures are automatically placed into universes based on their patched start address.

Starting output

Click START in the top bar, or use sACN → Start sACN Output (Ctrl+Shift+O). The dot turns green and the badge reads sACN ON. LightScript then transmits all fixture values continuously at the configured fps rate.

sACN Settings

Click the ⚙ button next to the sACN status cluster, or go to sACN → sACN Settings.

SettingDescriptionDefault
Network InterfaceWhich network adapter to transmit from. "Auto" uses the system default.Auto
Source NameThe name broadcast in sACN packets. Receivers use this to identify the source.LightScript
PrioritysACN priority (1–200). Higher priority wins when multiple sources exist. 100 is the standard default.100
Refresh RateHow many packets per second are sent. 40fps is recommended. Maximum is 44fps (E1.31 spec limit).40

Blackout

Press Ctrl+B or go to sACN → Blackout. This zeroes all dimmer values locally and pushes a zero frame over sACN immediately.

ℹ

sACN uses UDP multicast. Your network switch must support multicast, or the computer and nodes must be on the same layer-2 segment (direct connection or unmanaged switch). Managed switches may need IGMP snooping enabled.

Cuelists

A cue is a snapshot of your programmer state with a name, a cue number, a fade time, and an optional delay time. Cues are stored in the cuelist and fired in sequence with GO.

Storing cues

Set your fixtures to the desired state using SET/FADE commands, then:

STORE CUE.5 Opening Scene

The default fade time (set in Settings) is used. Cue numbers can be any string — 1, 1.5, 10A are all valid.

Firing cues

Click GO ▶ to advance to the next cue. Click ◀ BACK to return to the previous. Click the ▶ button on any individual cue row to jump directly. Press Space from anywhere in the app to GO.

Stopping fades

Click ■ STOP to halt all running fades immediately at their current value.

Presets

Presets store parameter values that can be instantly recalled onto selected fixtures. There are three types:

TypeStoresExample
INTDimmer/intensity levelSTORE PRESET.INT.1 Full
COLColour (red, green, blue)STORE PRESET.COL.3 Red
POSPosition (pan, tilt)STORE PRESET.POS.1 Center

To recall a preset, first select your fixtures in the Grouping Grid, then click the preset button. Intensity presets fade in over 1 second. Colour presets snap.

✓

You can use any type label, not just INT/COL/POS. STORE PRESET.FX.1 Strobe is perfectly valid.

Faders

The Faders panel provides eight named fader strips. Faders are free-form — they represent a level but do not automatically control specific fixtures unless you wire them up via Links.

Using faders

Drag the track up or down to set a level (0–100). Click the GO button at the bottom of a strip to toggle between 0 and 80. Click RELEASE ALL to zero every fader at once.

Labelling faders

STORE FADER.3 Wash
STORE FADER.1 Grand Master

Links (OSC) ADVANCED

The Links tab lets you map incoming OSC messages (or internal triggers) to any LightScript command. This enables external control from apps like TouchOSC, QLab, Ableton Live, or any OSC-capable software.

Creating a link

Go to the Links tab and click + Add Link. You'll be prompted for two values:

  • Source — the OSC address to listen for, e.g. /show/cue/$n$
  • Target — the LightScript command to execute, e.g. CUE.$n$

Variable capture with $VAR$

Wrap part of the OSC address in dollar signs to capture it as a variable. That variable is then available in the target command:

# Source: /show/cue/$n$
# Target: CUE.$n$
# → receiving /show/cue/5 fires CUE.5

# Source: /fix/$id$/dimmer
# Target: SET FIX $id$ dimmer 100
# → receiving /fix/3/dimmer sets fixture 3 to full

Deleting a link

Click the ✕ on the link row, or use the command line: DELETE LINK.1 (links are numbered 1-indexed from top).

ℹ

OSC hardware integration requires a Raspberry Pi build. The Links tab stores your routing rules now, ready to activate when hardware is connected.

3D Visualizer 3D VIZ TAB

The 3D Visualizer renders your stage in real time. Fixtures are shown as circles hanging from trusses. When their dimmer is above zero, a beam cone is drawn to the floor with a pool glow.

Camera controls

ControlAction
Drag (left mouse)Rotate camera around the stage
Scroll wheelZoom in/out

What you see

Each fixture shows its ID number. Selected fixtures have an amber ring. The beam colour reflects the fixture's current red/green/blue values. The floor pool scales with dimmer intensity. The HUD in the top-left shows how many fixtures are active.

The visualizer only renders when the 3D Viz tab is open — it does not consume CPU while you are on other tabs.

Show Files .lss

Show files use the .lss extension and are plain JSON. They capture your entire show state.

What is saved

  • Show name
  • All patched fixtures (profile, mode, address, current parameter values)
  • Full cuelist
  • All presets (INT, COL, POS)
  • Fader labels and levels
  • All links (OSC routing)
  • Variables ($VAR$)
  • Stored effects and timelines
  • Grid column count

Saving

Press Ctrl+S / Cmd+S for Save, or Ctrl+Shift+S for Save As. Use File → Save Show from the menu bar.

Opening

Press Ctrl+O / Cmd+O, or use File → Open Show. Loading a show stops all running fades, clears selection, and resets the current cue to -1.

New show

Use File → New Show (Ctrl+N). You'll be asked to confirm. All state — including variables, timelines, and effects — is cleared.

✓

Because .lss files are plain JSON, you can open them in any text editor, version-control them with git, or programmatically generate them.

Troubleshooting

App won't start — "electron: command not found"

You need to run npm install inside the lightscript folder first. This downloads Electron. It only needs to be done once.

App crashes on launch — EPERM uv_cwd

Your terminal's working directory no longer exists (you probably moved/replaced the folder while inside it). Close the terminal, reopen it, and cd into the folder again.

sACN output is ON but fixtures aren't responding

  • Check that the DMX start address in the patch matches the fixture's address setting
  • Check that the fixture profile and mode match the fixture's actual channel count
  • Try setting the network interface explicitly in sACN Settings instead of "Auto"
  • Check your switch supports multicast; try a direct connection or unmanaged switch
  • Verify the fixture/node is on the same subnet as your computer

Fixtures appear in wrong universe

Fixtures are automatically placed into universes based on address: addresses 1–512 go to universe 1, 513–1024 to universe 2, etc. Check the fixture's start address in the Patching tab.

Fades don't reach their target value

If you issue a new SET or FADE command on the same fixture and parameter while a fade is running, the previous fade is cancelled. This is by design.

Command line shows "No fixtures matched"

Either the fixture IDs you specified don't exist in the patch, or you used sel without any fixtures selected. Check the Grouping Grid.

Show file won't load

The file may be from an older version. Open it in a text editor and check the JSON is valid. The version field should be 2 for v2.0 show files.
